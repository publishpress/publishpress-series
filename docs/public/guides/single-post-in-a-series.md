# Display on a Single Post in a Series

In this guide, we’ll introduce the display on a single post in a series.

The display in a screenshot below is a default WordPress post, with extra features added by [PublishPress Series](https://publishpress.com/links/series). There are three items created by the [PublishPress Series](https://publishpress.com/links/series) plugin.

1. [Series Post Details](https://publishpress.com/knowledge-base/series-post-details/)
2. [Series Post List Box](https://publishpress.com/knowledge-base/the-post-list-box/)
3. [Series Post Navigation](https://publishpress.com/knowledge-base/series-post-navigation/)

![](https://docs-media.publishpress.com/publishpress-series/series-post-layout-29b20cc8ec.webp)

The settings for this display are controlled by going to Series > Settings.

1. **Post Details**: This shows information about where this post in the series. For example, the Post Details box may say “This entry is Part 2 of 3 in the series”.
2. **[Post List Boxes](https://publishpress.com/links/post-list-boxes)**: This is the Series [Post List Box](https://publishpress.com/links/post-list-boxes) option. It shows a list of all the posts in the series.
3. **Post Navigation links**: This is the Series Post Navigation feature. It shows “Previous” and “Next” links so users can navigate to other posts in the series.
