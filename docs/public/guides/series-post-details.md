# Series Post Details

Series Post Details is a key feature in the [PublishPress Series](https://publishpress.com/links/series) plugin. This feature allows you to show where a post stands inside a series. The typical display will appear this way: “This entry is part 3 of 8 in the series How to Use WordPress”.

This screenshot below shows the Series Post Details placed at the top of a post. The order of the posts is controlled via [the Manage Series screen](https://publishpress.com/knowledge-base/usage-publisher-screen/).

![Series Post Detials](https://docs-media.publishpress.com/publishpress-series/series-post-details-05fd71aee6.webp)

It is possible to customize this design from inside the “Series Post Details” screen. You can choose which of these layouts is active by going to “Settings”, then “Templates”, then “Series Post Details Selection”.

You can customize these designs by clicking the “Edit” link on any of the rows in the screenshot below.

![Series Post details](https://docs-media.publishpress.com/publishpress-series/series-post-details-screen-7fd5da1347.webp)

On the edit screen for each Series Post Details area, you are able to make changes to the design and layout. There are two areas that you can customize are shown in the screenshot below.

- **General**: The text showing inside the box.
- **Styling**: The colors, fonts, and padding for each box.

It is also possible to create a completely unique version of the Series Post Details. This can be done using [the Templates feature](https://publishpress.com/knowledge-base/series-post-list-template/) in [PublishPress Series](https://publishpress.com/links/series).

![Series Post Details](https://docs-media.publishpress.com/publishpress-series/series-post-details-general-7034ece482.webp)
