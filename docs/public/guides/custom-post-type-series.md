# Custom Post Types (Pro)

This feature requires the Pro version of the PublishPress Series plugin.

Custom Post Type support is available in the Pro version of [PublishPress Series](https://publishpress.com/links/series).

With this feature, you use [PublishPress Series](https://publishpress.com/links/series) with WordPress posts, plus also with pages and any other post type.

Your series can even have parts across different post types. That means you could have “Part 1” that is a post, “Part 2” that is a page, and “Part 3” that is another post type.

Go the Series > Settings > Post Types and choose the post types you want to work with:

![Post Types tab in PublishPress Series](https://docs-media.publishpress.com/publishpress-series/custom-post-type-selection-426b5f1bc8.webp)

*Post Type Series*

You can enable or disable this feature by going to “Series”, then “Settings”, and clicking the “Pro Features” tab.
