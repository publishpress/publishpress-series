# Series Post List Boxes

Post List Boxes are a key feature in the [PublishPress Series](https://publishpress.com/links/series) plugin. This feature displays a customizable box that allows you to display all the posts in the current series. You can choose to show the post title, featured image, author, publishing date, and much more.

This screenshot below shows a Post List Box placed at the top of a post. All three posts listed in this box are in the same series. The order of the posts is controlled via [the Manage Series screen](https://publishpress.com/knowledge-base/usage-publisher-screen/). This screenshot shows the “Default List Box” view.

![Post List Box example](https://docs-media.publishpress.com/publishpress-series/post-list-box-example-521826047f.webp)

This next screenshot shows the “Grid Style Box” view:

![Grid style box](https://docs-media.publishpress.com/publishpress-series/series-post-details-grid-0eb4b1789e.webp)

It is possible to customize these designs from inside the “Post List Boxes” screen. You can choose which of these layouts is active by going to “Settings”, then “Templates”, then “Post List Box Selection”.

You can customize these designs by clicking the “Edit” link on any of the rows in the screenshot below.

![Post List Boxes Screen](https://docs-media.publishpress.com/publishpress-series/post-list-boxes-screen-c6993d449c.webp)

On the edit screen for each Post List Box, you are able to make changes to the design and layout. There are three areas that you can customize are shown in the screenshot below.

- **Box Container**: The area containing all the posts.
- **Post**: The details of each individual post.
- **Layout**: The overall layout of the multiple posts.

It is also possible to create a completely unique version of the Post List Box. This can be done using [the Templates feature](https://publishpress.com/knowledge-base/series-post-list-template/) in [PublishPress Series](https://publishpress.com/links/series).

![Design and layout of the Post List Box](https://docs-media.publishpress.com/publishpress-series/edit-post-list-box-479be8a904.webp)
