# Series Post Navigation

Series Post Navigation is a key feature in the [PublishPress Series](https://publishpress.com/links/series) plugin. This feature allows users to navigate the previous or next post in a series. There will be a Previous arrow and a Next arrow.

This screenshot below shows the Series Navigation placed at the bottom of a post. The order of the posts is controlled via [the Manage Series screen](https://publishpress.com/knowledge-base/usage-publisher-screen/).

![Series Post Navigation](https://docs-media.publishpress.com/publishpress-series/post-navigation-1-b0a614d0df.webp)

It is possible to customize this design from inside the “Series Post Navigation” screen. You can choose which of these layouts is active by going to “Settings”, then “Templates”, then “Post Navigation Selection”.

You can customize these designs by clicking the “Edit” link on any of the rows in the screenshot below.

![Post Navigation Options](https://docs-media.publishpress.com/publishpress-series/post-navigation-options-6f863fa120.webp)

On the edit screen for each Series Post Details area, you are able to make changes to the design and layout. There are two areas that you can customize are shown in the screenshot below.

- **General**: The title and general settings.
- **Item**: The design of a single post link inside the navigation box.
- **Layout**: The colors and padding for each box.

![Navigation box](https://docs-media.publishpress.com/publishpress-series/post-nav-editor-75a3a456af.webp)

There are two more layout options provided by default. This next screenshot shows the “Image Navigation” display:

![Image Navigation display:](https://docs-media.publishpress.com/publishpress-series/image-navigation-07830f7f6e.webp)

This next screenshot shows the “Button Navigation” display:

![Button Navigation](https://docs-media.publishpress.com/publishpress-series/button-navigation-2e66a30f1b.webp)

It is also possible to create a completely unique version of the Series Post Navigation. This can be done using [the Templates feature](https://publishpress.com/knowledge-base/series-post-list-template/) in [PublishPress Series](https://publishpress.com/links/series).

![Series Post Details](https://docs-media.publishpress.com/publishpress-series/series-post-details-general-7034ece482.webp)
