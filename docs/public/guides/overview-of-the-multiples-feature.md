# Adding Posts to Multiple Series (Pro)

This feature requires the Pro version of the PublishPress Series plugin.

The Pro version of [PublishPress Series](https://publishpress.com/links/series) has a feature called “Multiple Series” that allows you to add posts to more than one series. The core plugin only allows posts to be added to one series.

When this feature is enabled, the “Series” metabox will allow you to choose more than one series, as in the screenshot below.

![Multiple Categories and the Post Edit screen](https://docs-media.publishpress.com/publishpress-series/series-multiples-box-b0d647a85c.webp)

*Multiples*

You will also see a similar change on the “Quick Edit” screen for posts, as in this screenshot below:

![Multiple Categories and Quick Edit](https://docs-media.publishpress.com/publishpress-series/series-quick-edit-4e83c9ba8d.webp)

*Multiples Quick Edit*

This feature can be enabled by default in the Pro version of the plugin. It can be disabled by going to Series > Settings, then the “Pro Features” tab.

![Enable the Multiple Series feature](https://docs-media.publishpress.com/publishpress-series/multiple-series-option-360bc392c3.webp)
