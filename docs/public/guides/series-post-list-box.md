# The Post List Box Shortcode

This feature requires the Pro version of the PublishPress Series plugin.

`[series_post_list_box]` is a shortcode that is available in the Pro version of [PublishPress Series](https://publishpress.com/links/series). This outputs the table of contents for a single series.

## How to use this shortcode [#](#h-how-to-use-the-series-post-list-box-shortcode)

If you include this shortcode in a post that is a part of a series, then the post list will be shown for that series: `[series_post_list_box]`

You can also include the series ID of a specific series. For example, this will show the posts in the series with the ID of 2: `[series_post_list_box series=2]`

## How to customize this shortcode [#](#how-to-customize-the-series-post-list-box-shortcode)

You can change the appearance of this shortcode by going to [the Post List Boxes screen](https://publishpress.com/knowledge-base/the-post-list-box/) and modifying the settings.

You can also dive deeper into customizing this display by using [the Post List Boxes Templates feature](https://publishpress.com/knowledge-base/series-post-list-template/).
