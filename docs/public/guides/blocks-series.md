# PublishPress Series and the Block Editor

The [PublishPress Series](https://publishpress.com/links/series) plugin allows you to collect WordPress content together into a series. This is ideal for magazines, newspapers, short-story writers, teachers, comic artists, or anyone who writes multiple posts on the same topic.

You can easily create beautiful layouts with [PublishPress Series](https://publishpress.com/links/series). This is possible thanks to an integration with the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin.

To create your layouts, start with both PublishPress Series and [PublishPress Blocks](https://publishpress.com/links/blocks) installed.

- Go to “Series” then “Publish Series”.
- Click “Update order”.
- On this screen, you can make sure all your posts are in the correct order. In the image below, my posts are incorrectly sequenced. I need to drag-and-drop them into a better order.

![Series Order Star Wars](https://docs-media.publishpress.com/publishpress-series/series-order-star-wars-68c097b0da.webp)

*Series Order Star Wars*

- Go to write a post using the Gutenberg editor.
- Choose the “Content Display” block.

![Content Display Block](https://docs-media.publishpress.com/publishpress-series/content-display-block-4f08c31513.webp)

*Content Display Block*

- In the sidebar for the Content Display block, choose your series from the “Show content with these Series” box.

![Choose Series](https://docs-media.publishpress.com/publishpress-series/choose-series-d7b1c6244d.webp)

*Choose Series*

- If you want to use the order of posts in the Series to control your display, you can do that by using the “Order by” option. Choose the “Series order” option.

![Order By Series](https://docs-media.publishpress.com/publishpress-series/order-by-series-38d15b0edd.webp)

*Order By Series*

Now that you’ve done the setup, you can configure your display. This image below shows the default view you will see with the Content Display block:

![Default Star Wars View](https://docs-media.publishpress.com/publishpress-series/default-star-wars-view-ee6f8cb2e5.webp)

*Default Star Wars View*

Using the block settings, you can make modifications from this point. For example, you can change the number of columns to “3”. If you have the Pro version of Blocks, you can also move the title underneath the image. This next image shows the updated version of this view:

![Star Wars Layout](https://docs-media.publishpress.com/publishpress-series/star-wars-layout-9c5d6caa60.webp)

*Star Wars Layout*
