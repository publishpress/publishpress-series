# The Post Navigation Shortcode

This feature requires the Pro version of the PublishPress Series plugin.

`` is a shortcode is in the Pro version of [PublishPress Series](https://publishpress.com/links/series). It outputs the series navigation information for a particular series. This is the series navigation strip that automatically displays the next and previous post in a series.
