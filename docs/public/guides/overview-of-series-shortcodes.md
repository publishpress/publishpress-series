This feature requires the Pro version of the PublishPress Series plugin.

[PublishPress Series](https://publishpress.com/links/series) Shortcodes is a feature in the Pro version of [PublishPress Series](https://publishpress.com/links/series).

This provides a set of WordPress shortcodes that allow you insert series information into posts. These shortcodes are visible under the “Shortcodes” tab in Series settings.

![Series Shortcodes](https://docs-media.publishpress.com/publishpress-series/series-shortcodes-tab-12cc4bfe82.webp)

## The Post List Box Shortcode [#](#0-toc-title)

This shortcode enables you to insert a table of contents for a series. This shortcode will automatically detect which series is assigned to the post and output the series [post list box](https://publishpress.com/links/post-list-boxes) for that post. [Click here for more specific details on this shortcode](https://publishpress.com/knowledge-base/series_postlist_box/).

```
[series_post_list_box]
```

## The Post Details Shortcode [#](#1-toc-title)

This shortcode outputs the Post Details box. The default is series title, part number, number of posts in series. [Click here for more specific details on this shortcode](https://publishpress.com/knowledge-base/series_meta/).

```
[series_meta]
```

## The Post Navigation Shortcode [#](#2-toc-title)

This shortcode outputs the series navigation strip used to smartly navigate through the various posts in a series. [Click here for more specific details on this shortcode](https://publishpress.com/knowledge-base/series_nav/).

```
[series_nav]
```
