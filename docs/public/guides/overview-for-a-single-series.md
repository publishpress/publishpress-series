# Display for a Single Series

Every series created with the [PublishPress Series](https://publishpress.com/links/series) plugin has its own URL. The [PublishPress Series](https://publishpress.com/links/series) plugin uses the normal WordPress taxonomy feature so these Series pages will have the same design as your Tag and Category pages.

You can see an example of this overview in the screenshot below:

![All Movies](https://docs-media.publishpress.com/publishpress-series/all-movies-7b9c83293e.webp)

*All Movies*

These screens will normally be located at a URL such as this: https://example.com/series/your-series-name/. You can customize the base portion of this URL by going to Series > Taxonomy in your WordPress admin area and changing “Series Taxonomy Slug”.

![](https://docs-media.publishpress.com/publishpress-series/series-taxonomy-7cd95c3bdc.webp)
